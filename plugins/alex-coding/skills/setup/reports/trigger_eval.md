# Trigger Evaluation

The bundled semantic trigger smoke evaluated nine positive and twelve negative/near-neighbor cases at threshold `0.5`.

- Precision: `1.0`
- Recall: `1.0`
- False positives: `0`
- False negatives: `0`

Positive coverage includes create, align, reference-project setup, direct dependency/package addition and removal with unseen package names, Chinese dependency update, framework update, and adding a technical layer. Negative coverage includes Plan, Implement, multiple unseen feature-creation forms, feature UI changes that use the word “upgrade”, review-only/no-change dependency discussion, discussion-only, narrower platform setup, and deployment requests.

This is deterministic action-plus-foundation-object concept evidence, not model-judged routing evidence. Bare proper-noun shorthand without any package/dependency context remains outside this deterministic evaluator and depends on the Agent's semantic skill selection.
